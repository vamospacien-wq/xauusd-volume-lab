Wyckoff automático usa el máximo/mínimo de las velas anteriores, excluyendo la vela actual; Spring/Upthrust se consideran candidatos si el precio rompe y cierra de vuelta dentro del rango. El modo manual usa los niveles que ingreses. FVG se confirma al cierre de la tercera vela. Los order blocks son candidatos simples basados en última vela opuesta antes de un desplazamiento y ruptura; requieren validación visual. El modelo actual no usa objetivos de liquidez como salida automática.

7 · Limitaciones importantes

Este CSV contiene velas Bid y un campo volume de Dukascopy. No representa el volumen global de todo el mercado Forex ni permite identificar por sí solo el volumen comprador/vendedor ejecutado. Para Order Flow más detallado necesitaremos datos tick con Bid/Ask y sus volúmenes. Esta versión no envía órdenes ni conecta con un bróker.

El backtest es una primera prueba, no una promesa de rentabilidad. Solo permite una operación abierta por escenario; el CSV exportado incluye las marcas de tiempo e índices de señal, entrada y salida para auditarlo. Si en una misma vela se tocan stop y objetivo, se cuenta el stop primero (supuesto conservador). El coste de spread se descuenta según el parámetro configurado; no incluye deslizamiento real, cambios de spread ni comisiones del bróker.
